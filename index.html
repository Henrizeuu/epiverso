O gargalo fiscal

A busca manual de notas trava a sua contabilidade.

Depender de downloads manuais em portais instáveis ou lidar com duplicidade constante de XMLs corrompe seus dados e gasta horas da sua equipe.

Bloqueios na SEFAZ

Consultas repetidas ou feitas por sistemas amadores geram bloqueios de IP nos servidores de SC e RS, interrompendo totalmente a rotina fiscal.

Notas Duplicadas

Sistemas que não possuem gerenciamento de estado acabam baixando e processando o mesmo XML múltiplas vezes, estourando a memória e sujando os dados.

Desorganização de Pastas

Arquivos salvos todos juntos em um único diretório. Não há separação lógica entre CNPJs matriz, filiais, notas emitidas e notas destinadas.

Arquitetura de Engenharia

Construído para suportar volumes massivos sem gargalos de memória.

O sistema utiliza robôs em Playwright para extrair as chaves da NFC-e e faz a ponte nativa com a API da Maria e o sistema Boss. O resultado? Download direto, estruturado e com validade jurídica dos arquivos SEFAZ.

Desenvolvemos travas de sincronização de 4 horas para aniquilar o processamento de notas duplicadas e integramos o roteamento JB Cepil para manter a integridade total dos arquivos por empresa.

  • Robôs em Playwright para scraping preciso
  • Integração com API da Maria e sistema Boss
  • Separação de Pastas via JB Cepil (Emitidas/Destinadas)
  • Travas estritas de 4h (Anti-Duplicidade e Memória)

Pipeline de Dados

O percurso da nota até o sistema

INIT:01

Robô Playwright

Inicializa rotina em background nos portais de SC e RS para consolidação de chaves de acesso NFC-e/NF-e.

SYNC:02

API Boss & Trava

Requisições via API da Maria efetuam o download na SEFAZ apenas se o intervalo de 4h da trava foi respeitado.

ROUTING:03

JB Cepil Roteamento

Os XMLs salvos são despachados para pastas exclusivas (Emitidas / Destinadas) baseados em Matriz e Filial.

Detalhes de Implementação

O script armazena o timestamp da última execução bem-sucedida. Se uma nova requisição for feita antes de 4 horas, o sistema ignora o processamento. Isso reduz uso de RAM e impede o registro duplicado de XMLs na base.

Sim. Graças à integração construída sobre a lógica do JB Cepil, as consultas respeitam a raiz do CNPJ, roteando automaticamente os arquivos para os subdiretórios de filiais específicas, sempre separando "Emitidas" de "Destinadas".

Enquanto o Playwright lida com a raspagem complexa de portais, a API Maria e o sistema Boss fazem o handshake oficial para os downloads em lote direto do webservice da SEFAZ, garantindo a integridade fiscal do arquivo XML original.
